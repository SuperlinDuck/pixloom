# AI 电商 Campaign Generator
## MVP 完整方案 + 产品 Roadmap

---

# 一、项目概述

## 项目名称（暂定）

Flashloom

一句话定位：

> 上传商品图，一键生成整套电商营销素材。

不是“AI 生图工具”。

而是：

> AI 电商营销视觉生产系统。

---

# 二、行业背景

AI 电商出图已经从：

- 通用 AI 生图
- 商品背景替换

进入：

- 电商营销内容生产
- 品牌一致性
- 多平台素材自动化
- Campaign 自动生成

传统商品图工具的问题：

- 只能生成单张图
- 模板感重
- 不懂内容电商
- 不懂营销
- 不懂平台场景

而真正的电商需求是：

> 为一次营销活动快速生产一整套内容资产。

包括：

- 主 KV
- Banner
- TikTok 封面
- 小红书种草图
- 商品卖点图
- 广告素材
- 不同尺寸适配

因此，Flashloom 的核心目标是：

> 从“单张图片生成”升级为“Campaign 内容生成”。

---

# 第一阶段目标用户（最重要）

## 1. TikTok Shop 卖家

特点：

- 高频上新
- 高频活动

- 不会摄影

# 四、核心价值主张

## 用户现在的流程

上传商品 → 找设计 → 修图 → 做 Banner → 改尺寸 → 导出 → 发布

耗时：
- 数小时

---

## Flashloom 的流程

上传商品 → 选择营销场景 → 一键生成整套 Campaign

耗时：
- 30 秒 ~ 2 分钟

# 七、MVP 核心能力（P0）

---

# 1. 商品一致性（最重要）

要求：

- logo 不丢失
- 材质一致
- 商品不变形
- 颜色准确

这是商用底线。

---

# 2. 稳定性优先

优先级：

稳定 > 惊艳

商家更需要：

- 可控
- 可复用
- 可批量

而不是随机艺术感。

---

# 3. 模板化输出

MVP 阶段：

模板感不是问题。

重点是：

- 稳定
- 快速
- 高完成度

---

# 4. 极简 UX

目标：

> 30 秒内出结果。

不暴露：

- Prompt
- CFG
- Seed
- LoRA
- 模型参数

真正核心不是模型。

## 模板结构示例

```json
{
  "scene": "summer_sale",
  "platform": "tiktok",
  "style": "ugc",
  "layout": "vertical",
  "headline_position": "top-left",
  "background_prompt": "fresh summer lifestyle scene",
  "cta": true
}
```
